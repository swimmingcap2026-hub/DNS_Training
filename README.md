# SCREEN DNS SU-3200 WET Training

Interactive training material for a SCREEN DNS SU-3200-style single-wafer wet cleaning system.

## Features

- White-background interface with Traditional Chinese, English, and Japanese.
- Whole-tool and chamber 3D views.
- Transparent enclosure, cross-section, and exploded views.
- Wafer transfer and chamber process animations.
- Component explanations, process lessons, and knowledge checks.

## Viewing

Open `index.html` in a browser, or use this repository's GitHub Pages website after deployment.
The HTML file contains its required runtime assets for offline viewing; external reference links need internet access.

## Model scope

This is an educational reconstruction based on public information, not manufacturer CAD, an equipment operating procedure, or a production recipe.
